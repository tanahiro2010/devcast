// FEATURES

書く・管理する・配信するを、一つに。

01

Multi-Publish

1つの記事から、Qiita / DEV.to / はてなブログへ同時に公開。失敗しても他媒体をロールバックしないPartial Success設計。

02

Sync Detection

記事を更新すると、どの媒体が最新でどこが未反映かをRevision単位で自動検出。Outdatedな媒体だけ再投稿できる。

03

Content API

DevCastをHeadless CMSとして利用。自分のポートフォリオやブログから記事データを直接取得できる。
