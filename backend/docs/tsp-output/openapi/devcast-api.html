DevCast backend API (Slim Framework 4 / PHP).

Generated by hand-reading the live controllers under backend/src/Futures and backend/src/Config/routes.php, since the backend has no schema library (no zod / class-validator equivalent) to generate from automatically. Treat this spec as the source of truth for the HTTP contract; when the backend changes, update the corresponding .tsp file in this directory and recompile with bun run build.
